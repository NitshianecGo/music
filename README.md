# MusicWave

Современный статический музыкальный веб-плеер.

## Что уже есть
- поиск музыки через iTunes Search API;
- 30-секундные официальные превью, где они доступны;
- интернет-радио через Radio Browser API;
- избранное в `localStorage`;
- светлая/тёмная тема;
- адаптивный дизайн для телефона и ПК;
- GitHub Pages без собственного сервера.

## Как запустить на GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи `index.html`, `style.css` и `app.js` в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе Build and deployment выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`.
6. Сохрани. GitHub выдаст адрес сайта.

## Важное ограничение
«Искать любую музыку во всём интернете и воспроизводить её» одной статической страницей нельзя. Сайты вроде Spotify, YouTube и Apple Music защищают каталоги и потоковую передачу своими API, авторизацией и правилами лицензирования.

Этот проект специально использует публичные API и превью, чтобы его можно было разместить на GitHub Pages без backend-сервера.
