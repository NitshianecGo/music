# MusicWave V3

Обновлённая версия для GitHub Pages.

## Что исправлено

- Мобильное меню теперь закрывается:
  - повторным нажатием на кнопку;
  - выбором пункта меню;
  - нажатием по затемнённому фону;
  - клавишей Escape;
  - кликом вне меню.
- Меню имеет отдельный backdrop и корректный `z-index`, поэтому не должно перекрывать интерфейс после закрытия.
- Убран выбор источника. Поиск автоматически проверяет iTunes, YouTube, VK и Spotify, если источник настроен.
- Избранное работает для песен и радиостанций.
- Сердечко получает плавную pop-анимацию при добавлении.
- Кнопка Play в результатах поиска переключается в Pause для активного трека.
- Радио и музыка используют один аудиоконтур: при переключении источник останавливается корректно.
- YouTube теперь воспроизводится через официальный YouTube IFrame Player API, а не открывается просто новой вкладкой.
- Добавлен мини-плеер YouTube с полноценным видео/аудиовоспроизведением через официальный embed.
- В настройках есть YouTube/Google, VK и Spotify.
- Работает режим без аккаунта: YouTube embed, iTunes preview и Radio Browser не требуют пользовательского аккаунта.
- Spotify сохраняет PKCE-подключение.
- Сохраняется Supabase anonymous account для избранного/истории, если Supabase настроен.

## Важное про полноценную музыку

Нельзя безопасно и легально сделать универсальный «скачать звук из YouTube и проиграть его в фоне» через один JS-файл. Поэтому MusicWave V3 использует официальные способы:

1. **YouTube** — официальный embedded player. Это полноценное видео/аудио YouTube, а не 30-секундное iTunes preview.
2. **Spotify** — официальный Web Playback SDK. Для локального Web Playback Spotify требует Premium и OAuth. См. официальную документацию Spotify.
3. **Radio Browser** — поток радиостанции целиком.
4. **iTunes** — короткие preview оставлены как запасной источник, когда нет полноценного источника.

## Конфигурация

Скопируй `config.example.js` в `config.js` и заполни:

- `youtubeApiKey`
- `vkAccessToken`
- `spotifyClientId`
- `spotifyRedirectUri`
- при желании Supabase

YouTube search API key не означает обязательный Google-вход. Google-аккаунт нужен только для пользовательских Google/YouTube функций, которые ты отдельно захочешь подключить.

## GitHub Pages

Загрузи содержимое папки V3 в репозиторий и включи GitHub Pages.

Для Spotify в Dashboard нужно добавить точный `spotifyRedirectUri`.

## Ограничения

Не используется скачивание, извлечение или скрытое копирование чужого аудио. Полноценное воспроизведение идёт через официальные плееры/потоки.
